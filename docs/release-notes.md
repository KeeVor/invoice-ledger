## 票迹：本地发票识别与台账

- Windows x64 安装包内置本地识别引擎，无需安装 Python 或 Node.js。
- 应用内可检查和下载新版；确认后退出并安装，不额外创建更新前备份。
- 待核对发票支持多选、批量归属和一键核对；校验失败的项目逐条保留并显示原因。
- 统计支持按自定义归属分组，并可进入台账查看对应发票和项目明细。
- 已归档的错误记录可以单张永久删除，确认后清理不再被引用的原件和预览。
- 修复票面项目名称换行时后续行可能漏识别的问题。
- 普通自动备份只保留最新 1 份，新备份校验成功后才删除旧备份；恢复前也不额外备份，手动导出的备份不自动删除。
- PDF / 图片识别、人工核对、查重、台账、金额统计、Excel 导出与完整备份。

### 下载与升级

下载 `Piaoji-Setup-版本号.exe`。其余 `.blockmap`、`latest.yml` 为更新所需元数据，用户无需手动下载；`SHA256SUMS.txt` 用于校验。

v0.2.2 及更早版本请先手动安装新版，之后可通过「数据与备份」检查更新。升级前正常退出旧版并保留原安装位置。

### 使用前须知

- 安装包暂未签名，Windows 可能提示未知发布者；请核对下载来源。
- OCR 不是验真，保存前务必核对号码、日期、金额等信息。
- 发票和账本保存在本机，不会上传。账本和备份未加密，请妥善保管。
- 尚未在另一台干净 Windows 电脑上完成安装与覆盖升级验证。

完整变更见仓库 `CHANGELOG.md`，数据口径和限制见 `README.md`。
